# COIS-1020H — Official Lab 1–8 reproduction specification

**Source of truth:** original Lab 1–8 PDFs in [source-material/cois-anki-tether](https://github.com/bywale-com/anki-tether/tree/main/source-material/cois-anki-tether). This is an independent **study checklist**; it does not replace instructor instructions or authorize AI use in assessed submissions. Source text has been extracted page by page in `study-material/COIS-1020/labs/`; confirm code/figures in the original PDFs.

**Pass rule for each lab:** (1) reconstruct from an empty console project without AI or step-by-step instructions; (2) compile/run; (3) reproduce all specified behavior, edge cases, and debugging observations; (4) explain key control flow and parameter semantics aloud; (5) record timestamp, output and any mistakes. If first attempt fails, record what failed, revise, and do a new independent retest later. No lab is currently certified complete.
